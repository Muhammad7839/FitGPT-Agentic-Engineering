## Current decision

No indexed reference documents are currently required.

Existing committed reports, documentation, configuration, implementation, and tests remain directly discoverable through their repository paths. They should not be duplicated into this layer.

## Add a reference when

- A large or infrequently needed source is difficult to locate through normal repository documentation.
- A sanitized external design source becomes necessary for occasional project work.
- A historical collection becomes too large to load or inspect routinely.

Every added reference must include:

- A concise description
- Source or provenance
- Relevant tasks
- Last-reviewed date
- Review or removal trigger

## Ownership and write policy

Human-maintained and read-only for agents.

Agents may recommend adding or updating a reference but must not modify this directory or its permissions.

## Pruning schedule

Review this index every 180 days and whenever a listed source is superseded.
